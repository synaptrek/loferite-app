# Loferite

**Neuroimaging Toolkit.**

Loferite is an iOS app for viewing neuroimaging and EEG data, intended for research and education. It is **not** a medical device and is not intended for clinical or diagnostic use.

## Test package

A set of sample files to try Loferite's viewers: anatomical MRI, fMRI, surfaces, DICOM, EEG, tractography and an X-ray angiography test object. The package is provided **only for testing the viewer**, for educational use and not for diagnostic use. It is **not** shipped with the app.

Every file comes either from a public dataset released under **CC0 1.0** (Public Domain Dedication) or is a synthetic test file. None contains identifiable patient information. Files marked **derived** were created by the app's author from the source data listed below and are not part of the original datasets.

The full list of files, sources and licenses is in **`references.txt`**, inside the zip.

## Privacy in short

Loferite does not collect any data. Everything you import stays on your device, is excluded from backups, and is never transmitted. The app includes no analytics, tracking or advertising.

The full policy, including your rights under the GDPR, is on the [web page](https://synaptrek.github.io/loferite-app/#privacy) and in the app.

## Support

Found a problem, or have an idea? Write to **loferite [at] tuta [dot] io**, or use **Settings ▸ Support ▸ Send feedback** inside the app, which opens a pre-filled email in your Mail app that you review and send yourself.
Please don't include personal, patient or research-subject information, or any images, in your message.
